# Exact-version MT6768 source candidate — 2026-08-21

## Candidate

`realme-kernel-opensource/realmeC3-narzo10A-narzo10-6i-kernel-source` at commit `e469e38485983832347674c504fdc372ea41d4bb` is an exact Linux 4.14.141 source tree: its top-level Makefile reports `VERSION=4`, `PATCHLEVEL=14`, `SUBLEVEL=141`.

The tree contains the MT6768 MSDC stack at:

- `drivers/mmc/host/mtk-sd.c`
- `drivers/mmc/host/mediatek/ComboA/sd.c`
- `drivers/mmc/host/mediatek/ComboA/mt6768/msdc_cust.c`
- `arch/arm64/boot/dts/mediatek/cust_mt6768_msdc.dtsi`
- `scripts/dtc/include-prefixes/dt-bindings/mmc/mt6768-msdc.h`

The public MT6768 DTS fragment is structurally extremely close to the stock X683 DTB and uses the same DT property names, storage capabilities, pinctrl groups, supply topology and clock names.

## Why this is the current strongest baseline candidate

It matches the stock kernel sublevel exactly (`4.14.141`) rather than merely sharing the MT6768 platform. The DT binding also proves the exact numeric meanings of the recovered stock values:

- `MSDC_EMMC = 0`
- `MSDC_SD = 1`
- `MSDC1_CLKSRC_200MHZ = 2`
- `MSDC_SMPL_RISING = 0`

## Known differences / non-proof

- The public `mtk-sd.c` probe requests clocks named `source`, `hclk`, and optional `source_cg`, while the stock X683 DT contains `msdc0-clock`, `msdc0-hclock`, `msdc0-aes-clock`, `msdc1-clock`, and `msdc1-hclock`.
- Public SD card-detect uses GPIO 18; stock X683 uses GPIO 4.
- The stock binary contains an `msdc_of_parse` symbol and a larger vendor-specific MSDC symbol graph; exact source-level correspondence to the public files has not been proven.

Therefore this tree is the **current strongest exact-version source candidate**, not yet the exact X683 source baseline.

## Integration posture

Do not import the public driver unchanged. Use it to reconstruct the vendor baseline, then derive X683-specific deltas from the stock executable, kallsyms, configuration and DTB. The first driver target remains the request/IRQ/DMA/tuning/CQHCI/PM/DT graph rooted at the recovered stock MSDC symbols.
