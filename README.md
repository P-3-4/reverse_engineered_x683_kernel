# Reverse-Engineered X683/H694 Kernel

Reconstruction of the Infinix X683/H694 MT6768 Linux 4.14.141-era kernel from stock binaries, configuration, DTB/DTBO, symbols, and public 4.14/MT6768 reference sources.

## Status

Early reconstruction. F2FS layout and Transsion GC are under active reverse engineering.

## Method

Recovered code is labelled reconstructed/inferred. It is not represented as original proprietary Transsion source.

## First milestone

Build a functionally equivalent 4.14.141-era X683/H694 kernel capable of booting stock userspace. Kernel modernization follows only after the stock-equivalent build is established.
